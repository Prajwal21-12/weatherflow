WeatherFlow 🌤️

A real-time weather forecast application built using HTML, CSS, and JavaScript.

Features

- Search for cities around the world
- Display current temperature and feels-like temperature
- Show weather conditions with dynamic icons
- Display humidity, wind speed, and atmospheric pressure
- Provide a 5-day weather forecast
- Handle invalid city names and API errors
- Responsive user interface

Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API and async/await
- OpenWeatherMap API

How to Run

1. Clone or download this repository.
2. Open "index.html" in your browser.
3. Enter a city name and click Search.

API

Weather data is provided by OpenWeatherMap.
